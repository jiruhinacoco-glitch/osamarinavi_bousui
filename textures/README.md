# 3Dの質感に使う写真（テクスチャ）

## いま入っているもの

| ファイル | 何の絵か | 出どころ |
|---|---|---|
| `concrete_color.jpg` | コンクリートの**色** | ambientCG「Concrete034」1K-JPG |
| `concrete_normal.jpg` | コンクリートの**凸凹**（法線） | 同上（**NormalGL**） |
| `concrete_rough.jpg` | コンクリートの**つやの具合** | 同上（Roughness） |

- 出どころ：https://ambientcg.com/ の Concrete034（**CC0＝著作権を放棄した素材。
  商用でも自由に使えて、出どころの表示も要らない**）
- 大きさは 1024×512（**横長の 2:1**）。3枚とも同じ大きさ・同じ並び。

## 使われ方（zumen_sekisan.html の `nn-phototex-js`）

- **3Dタブを開いたときだけ読む**。ページを開く速さは変わらない。
- 貼るのは**躯体・外壁（`nnMat` の `concrete` と `wall`）**だけ。
- **1タイル＝よこ2m×たて1m**。写真が 2:1 なので、貼る四角も 2:1 にそろえている
  （そろえないと粒や気泡が縦につぶれて見える）。
- **この3枚が無くても壊れない**。読めなければ、今までどおり
  「その場で粒を描く」手描きの質感になる。

## 差し替えるとき

同じ名前で置き換えるだけ。**縦横比が変わるときは**
`nn-phototex-js` の `TILE_W` / `TILE_H` を写真の縦横比に合わせること。

★同じ名前で中身だけ差し替えると、ブラウザが古い絵を使い続ける。
URLに版名（`?v=…`）を付けてあるので、**版名4点セットを上げれば新しい絵に入れ替わる**。
