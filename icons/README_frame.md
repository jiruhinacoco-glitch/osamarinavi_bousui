# パネルの四隅の角（frame_c_*.png）

- `frame_panel_src_corner.png` … 佐野さんが描いた左上の角（元絵・756×756）＝**色の見本として使う**
- `frame_c_tl / tr / bl / br .png` … 実際に使う四隅の絵（300×300）

## 決まり（本人の指示）
- **絵は四隅にだけ置く。辺には使わない。**
- 枠そのものは細い線1本（`border:1.5px solid #cfdcd3`）。
- 見出しの帯のすぐ下に境界線。

## ★比率がいちばん大事
| | 帯の太さ ÷ 角の大きさ |
|---|---|
| 見本（パワプロ） | **13%** |
| 元絵そのまま | 45%（3.5倍太い） |

元絵をそのまま拡大縮小すると「角は大きく・帯は細く」が両立できない
（小さくすると角が消え、大きくすると帯が塩ビパイプのように太くなる）。
そこで **色は元絵から採り、比率だけ見本に合わせて描き起こしている**。

`scratchpad/build_frame.py` の数値：
- 角の1辺 300px（画面では `--cs`：PC 46px／スマホ 34px）
- 帯 = 角の **13%**（39px → 画面6px）
- フチ = 帯の **15%**（6px）
- 外側の丸み = 角の **19.5%**（58px → 画面9px）
- 色：フチ `#a4acad` ／ 中身 `#c4cbcc`（元絵から自動で採る）

## ★腕の先端は「線で閉じる」（ふさぎ）
閉じないと切り口の中身の色がむき出しになり、切りっぱなしに見える。
`build_frame.py` が先端 WO px を フチの色で塗って閉じている。

## CSS 側（kirokucho_demo.html の `<style id="nn-panelframe">`）
- `#dashboard .dpanel::before` の背景に4枚を四隅へ置く。大きさは `--cs`。
- **`border-radius` は角の絵の外側の丸みに合わせること**（46pxなら9px）。
  合わせないと角の絵の外に枠線がはみ出して二重に見える。
- 絵のURLには版名を付ける（`nn-panelframe-js` が `--nnc-tl` などに入れる）。
  同じ名前で描き直したとき、ブラウザが古い絵を使い続けるのを防ぐため。

色や形を変えたいときは `build_frame.py` の数値を直して流し直す。
