# パネルの枠（frame_panel.png）の作り直し方

- `frame_panel_src_corner.png` … 佐野さんが描いた**左上の角1枚**（元絵）
- `frame_panel.png` … それを枠に組み立てたもの（アプリが使うのはこちら）

組み立ては `scratchpad/build_frame.py`。

## 作りの決まり（見本＝パワプロのメニューに合わせた）
**辺は細い帯／四隅だけ太い帯**で、その境目に**段**が付く。
もらった絵は太い帯だけなので、同じ色（フチ #a4acad ／中身 #c4cbcc）で
細い帯（太い帯の48%）を作り、角の先に段を付けている。

## 手順（build_frame.py がやっていること）
1. 元絵の外側（左上）から 300px 角を切り出す
2. まっすぐな部分の断面を測って「フチの太さ・フチの色・中身の色」を求める
3. 角から238pxの位置で**太い→細いの段**を付け、そこから先を細い帯にする
4. 対角線で折り返して、横の腕とたての腕を完全に同じにそろえる
   （元絵は太さも色の濃さも違ったため。そろえないと上下の辺と左右の辺で明るさが変わる）
5. 角を鏡で反転して4隅を作り、辺は細い帯の断面を引き伸ばす
6. 出来上がり 648×648px（角300px＋中央48pxが伸びる部分）

## CSS 側（kirokucho_demo.html の `<style id="nn-panelframe">`）
`border-image: url(...) 300 / 18px / 0 stretch` ＋ `border-radius:12px`
- 画面で**細い帯を約4px**にしたいので `4 ÷ (65/300) ≒ 18px` を border-width に
- 背景の角は `194 × (18/300) ≒ 12px` で丸める
  （border-image は border-radius に切り取られないが**背景は切り取られる**ので、
   合わせないと帯の外に白い角がはみ出す）
- `fill` は付けない（中央はパネル本来の背景を使う）

絵を描き直したら、元絵を `frame_panel_src_corner.png` に上書きして
`python3 build_frame.py` を流し直すだけ。
