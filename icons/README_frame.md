# パネルの四隅の角（frame_c_*.png）

- `frame_panel_src_corner.png` … 佐野さんが描いた**左上の角**（元絵・756×756）
- `frame_c_tl / tr / bl / br .png` … それを鏡で反転して作った4隅ぶん（300×300）

## 決まり（本人の指示）
- **絵は四隅にだけ置く。辺には使わない。**
- 枠そのものは細い線1本（`border:1.5px solid #cfdcd3`）。
- 見出しの帯のすぐ下に境界線。

## 作り方
`scratchpad/build_frame.py` を流すだけ。
元絵の絵がある範囲の左上から 300px 角を切り出し、鏡で反転して4枚保存する。
（対角線で折り返すなどの加工はしない。もらった絵をそのまま使う）

## CSS 側（kirokucho_demo.html の `<style id="nn-panelframe">`）
`#dashboard .dpanel::before` の背景に4枚を四隅へ置く。大きさは `--cs`（PC 46px／スマホ 34px）。
- **`border-radius` は角の絵の外側の丸みに合わせること**
  絵は 外側の丸み194px／角300px なので、46px で置くなら `194×46÷300 ≒ 30px`。
  合わせないと角の絵の外に枠線がはみ出して二重に見える。
- **左右と下の余白は、角の腕の太さ（角の大きさの約46%）より大きくとること**
  足りないと腕が中身の文字に重なる。上は「見出しの上が空きすぎ」との指摘があるので詰めたまま。
- 絵のURLには版名を付ける（`nn-panelframe-js` が `--nnc-tl` などに入れる）。
  同じ名前で描き直したとき、ブラウザが古い絵を使い続けるのを防ぐため。

絵を描き直したら、元絵を `frame_panel_src_corner.png` に上書きして
`python3 build_frame.py` を流し直すだけ。
