# models/ — Blenderで作った部品（.glb）の置き場

ここに `<部品の種類>.glb` を置くと、図面・積算の3Dで
**手続きモデルの代わりに Blender のモデルが表示される**（テクスチャもそのまま出る）。

- 例：`models/hatogoya.glb` → 鳩小屋がBlenderのモデルに差し替わる
- 置かなければ、内蔵の手続きモデル（台座・箱・笠木・配管）が出る

## Blenderからの書き出し方
1. 実寸（メートル）でモデリングする（原点＝底面の中心）
2. マテリアルは **プリンシプルBSDF**（ベースカラー／ラフネス／メタリック／ノーマルの
   テクスチャを使ってよい。焼き込み＝ベイクしたものが確実）
3. ファイル → エクスポート → **glTF 2.0 (.glb)**
   - 形式：glTF バイナリ (.glb)
   - 「+Yが上」= ON（既定）／「圧縮」= OFF（Draco圧縮は読めない）
4. テクスチャは 1024×1024 まで・**1ファイル 3MB 以内** を目安にする
   （サイトに同梱されるので、大きいと全員の読み込みが遅くなる）

★アプリ側は「部品の横幅（W）」に合わせて等倍で縮尺し、底を屋根の面に合わせる。

## いま受け皿がある部品

| ファイル名 | 何の部品か | 手続きモデル（.glb が無いときの姿） |
|---|---|---|
| `hatogoya.glb` | 鳩小屋（配管ボックス） | コンクリ台座＋箱＋笠木＋ステンレス配管 |
| `kaidan.glb`   | 屋上の階段           | 段板＋側桁＋手すり（蹴上げ190mm） |
| `vent.glb` ★同梱ずみ | 脱気筒（◆脱気筒）    | **無し**（.glb が姿そのもの） |

## 荷揚げ（材料の荷姿）の差し替え ★2026-09-28e

3Dの材料量の表示「📦 荷揚げを置く」で並ぶ荷姿は、1個ずつ Blender のモデルに差し替えられる。
**原点＝底面の中心・実寸（m）**で作る。アプリ側が下の大きさの箱に**等倍で収めて**並べる。

| ファイル名 | 荷姿 | アプリが収める大きさ（m） |
|---|---|---|
| `nz_roll.glb` | ルーフィングのロール（下張り等・立てた姿） | 直径0.20 × 高さ1.0 |
| `nz_roll_sand.glb` | 砂付ルーフィングのロール | 直径0.24 × 高さ1.0 |
| `nz_can.glb` | 一斗缶（18L・20kg以下の缶） | 0.238 × 0.35 × 0.238 |
| `nz_pail.glb` | ペール缶（セット品・大きい缶） | 直径0.32 × 高さ0.38 |
| `nz_bag.glb` | 袋（アスファルト等） | 0.45 × 0.12 × 0.30 |
| `nz_pallet.glb` | パレット | 材料の並びの大きさ × 高さ0.14 |

★ラベル（品名・kg）はアプリが材料ごとに描いているが、Blender のモデルに差し替えたものには付かない
　（品名の入ったテクスチャを焼き込むか、無地で作る）。置かなければ内蔵の手続きモデルで出る。

★ファイル名は「部品の種類（kind）」であって、ボタンの名前ではない。
　脱気筒はボタンが `dakki` でも kind は `vent` なので **`vent.glb`**。
　手続きモデルの無い部品を足すときは、HTML の `GLB_KINDS` にも1行足すこと
　（足さないと .glb を取りに行かない）。

**★.glb を置くだけで、そちらが優先されます。HTML は触りません。**
無いときは上の「手続きモデル」の姿で出るので、置く前でも使えます。
