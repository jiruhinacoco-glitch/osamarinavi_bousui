# models/ — Blenderで作った部品（.glb）の置き場

ここに `<部品の種類>.glb` を置くと、図面・積算の3Dで
**手続きモデルの代わりに Blender のモデルが表示される**（テクスチャもそのまま出る）。

- 例：`models/hatogoya.glb` → 鳩小屋がBlenderのモデルに差し替わる
- 置かなければ、内蔵の手続きモデル（台座・箱・笠木・配管）が出る

## Blenderからの書き出し方
1. 実寸（メートル）でモデリングする（原点＝底面の中心）
2. マテリアルは **プリンシプルBSDF**（ベースカラー／ラフネス／メタリック／ノーマルの
   テクスチャを使ってよい。焼き込み＝ベイクしたものが確実）
3. ファイル → エクスポート → **glTF 2.0 (.glb)**
   - 形式：glTF バイナリ (.glb)
   - 「+Yが上」= ON（既定）／「圧縮」= OFF（Draco圧縮は読めない）
4. テクスチャは 1024×1024 まで・**1ファイル 3MB 以内** を目安にする
   （サイトに同梱されるので、大きいと全員の読み込みが遅くなる）

★アプリ側は「部品の横幅（W）」に合わせて等倍で縮尺し、底を屋根の面に合わせる。

## いま受け皿がある部品

| ファイル名 | 何の部品か | 手続きモデル（.glb が無いときの姿） |
|---|---|---|
| `hatogoya.glb` | 鳩小屋（配管ボックス） | コンクリ台座＋箱＋笠木＋ステンレス配管 |
| `kaidan.glb`   | 屋上の階段           | 段板＋側桁＋手すり（蹴上げ190mm） |

**★.glb を置くだけで、そちらが優先されます。HTML は触りません。**
無いときは上の「手続きモデル」の姿で出るので、置く前でも使えます。
