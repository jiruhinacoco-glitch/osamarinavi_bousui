# _tools/ ＝ 一回きりの道具（合否を出さない・記録にも残っていない）

ここにあるのは、過去のセッションで**その場の調べもの**に使ったスクリプト。
・画面を撮るだけ（`*shot*`）
・数値を出すだけ（`*dbg*` / `probe*` / `sz*` / `meas` …）
・当時の作業に固有で、いまは同じことを別の検査がしている

**共通点は「○／★NG を出さない」こと**＝流しても合否が分からないので、
毎日の点検には使えない。消してはいないが、検査の一覧からは外してある
（本物の検査に混ざっていると、どれを流せばよいのか分からなくなるため）。

## 使うとき
`node _check/_tools/◯◯.js` でそのまま動く（中身は当時のまま）。
ただし**画面の作りが変わっていて動かないものが多い**。直すより、
`_check/` にある今の検査を読むほうが早いことがほとんど。

## 消していない理由
当時どうやって測ったか（どこを見て、何と比べたか）が書いてあるため。
同じ種類の調べものをするとき、書き方の見本になる。
